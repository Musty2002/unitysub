# Enable Firebase email/password sign-in

1. Open the Firebase Console and select the UNITYSUB project (`unitysub-8d27a`).
2. In the left menu, open **Build → Authentication**, then choose **Get started** if prompted.
3. Open **Sign-in method** (sometimes shown as **Providers**), select **Email/Password**, enable the Email/Password option, and save. Email link sign-in is optional and can stay off.
4. Return to UNITYSUB and create a new account. Confirm it appears in Authentication → Users, then try signing in.

No code changes are needed for this setup. Existing device-only demo accounts are not Firebase accounts, so create a new account after enabling the provider.
